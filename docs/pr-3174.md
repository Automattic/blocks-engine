## Summary

Remove empty HTML comments from button RichText and avoid unnecessary paragraph carriers.

Closes https://github.com/Automattic/blocks-engine/issues/3174

## Root cause and fix

`HtmlCompilation::createBlock()` normalized comments for paragraph/heading `content`, but omitted button `text`. `CommentTextRunBoundaries` also created a segment for every comment, including truly empty `<!---->` comments.

Route button `text` through the existing normalization primitive. In that primitive, remove empty comments without splitting the text run. Preserve the existing boundary carriers for whitespace/non-empty comments (including `<!-- -->`), as required by the existing boundary tests and parity corpus. No public signatures or site-specific paths added.

Register `tests/unit/empty-comment-richtext.php` in Composer's unit suite. It contains the issue's exact reduced HTML fixture and checks both block attributes and saved markup, telephone-link preservation, adjacent/nested empty comments, and mixed empty/non-empty comments.
