A `Card` is a raised surface that bundles related information — a header, body,
and optional footer — into one scannable unit. It's the building block for
dashboards, settings panels, and content grids.

## Example

## Guidelines

<DoDont>
  <Do>Keep one clear primary action per card.</Do>
  <Dont>Nest cards inside cards — flatten the hierarchy instead.</Dont>
</DoDont>

## Accessibility

- A whole-card link uses the "pseudo-content" pattern: a single `<a>` stretched
  over the card with `::after`, so the entire surface is one accessible target.
- When `interactive`, the card is keyboard-focusable and shows the standard
  `--halo-focus-ring`.

<Callout type="info">
  For a grid of cards, wrap them in a `<ul>` of `<li>` items so screen readers
  announce the count.
</Callout>
