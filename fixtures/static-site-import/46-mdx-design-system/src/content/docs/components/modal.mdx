A `Modal` is a dialog rendered above the page that **traps focus** and demands a
decision before the user can return to the underlying content. Use it sparingly —
it interrupts. For non-blocking messages, prefer a `Toast` or inline banner.

<Callout type="warning" title="Beta">
  Modal is in **beta** (since 2.1.0). The API is stable, but the
  `dismissOnOverlay` default may change to `false` in 3.0 — set it explicitly.
</Callout>

## Live example

The trigger below opens a real modal rendered into a portal. Focus moves to the
dialog, Tab is trapped inside it, and Escape closes it.

## Anatomy

A modal has a **title** (the accessible name), a **body**, and a **footer** for
actions. The overlay (scrim) dims and blocks the page behind it.

## Behavior

When a modal opens, Halo UI:

1. Saves the currently focused element to restore later.
2. Moves focus to `initialFocus`, or the first focusable child, or the dialog.
3. Sets `aria-hidden="true"` and `inert` on everything outside the dialog.
4. Traps Tab / Shift+Tab within the dialog.
5. On close, restores focus to the element from step 1.

```tsx
// Focus is restored to the trigger automatically on close.
<Modal open={open} onClose={close} title="Settings" initialFocus={firstFieldRef}>
  …
</Modal>
```

## Guidelines

<DoDont>
  <Do>Use a modal for a single, blocking decision the user must resolve now.</Do>
  <Dont>Stack modals on top of modals — close one before opening the next.</Dont>
</DoDont>

<DoDont>
  <Do>Make the destructive action clearly labeled ("Delete", not "OK").</Do>
  <Dont>Auto-open a modal on page load to show marketing content.</Dont>
</DoDont>

## Accessibility

- Renders `role="dialog"` with `aria-modal="true"`.
- `title` becomes the dialog's `aria-labelledby`; body text can be referenced via
  `aria-describedby`.
- **Escape** closes the dialog; focus is trapped while open and restored on close.
- The scrim has `pointer-events` enabled so the inert page behind cannot be
  interacted with — this is what makes it truly modal.

<Callout type="danger" title="Don't trap users">
  A modal must always offer a way out — a visible close button, Escape, or a
  Cancel action. Never remove all three.
</Callout>
